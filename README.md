# 👷‍♂️ Система контроля наличия касок на стройплощадке (Construction PPE Detection)

Проект по автоматическому обнаружению средств индивидуальной защиты (защитных касок) и фиксации нарушений требований безопасности с использованием нейронных сетей семейства YOLO. Выполнен в рамках производственной практики (МТУСИ).

## 📌 Описание проекта
Цель системы — мониторинг строительной площадки, выделение людей без защитных касок, сохранение случаев нарушений и формирование статистики. 
В задаче решаются проблемы перекрытий (occlusions) и ложных срабатываний на сложном фоне.

## 📊 Набор данных и архитектуры
- **Датасет:** Construction-PPE (1416 изображений).
- **Классы:** `helmet` (каска), `no_helmet` (без каски), `person` (человек).
- **Исследованные модели:** YOLO11n, YOLOv8n, YOLOv8s, YOLOv8m, YOLO12n.

### Результаты сравнения моделей (на 30 эпохах)

| Модель | mAP50 | mAP50 (helmet) | mAP50 (no_helmet) | Скорость инференса |
| :--- | :---: | :---: | :---: | :---: |
| **YOLO11n** | 0.596 | 0.850 | 0.483 | 3.8 мс |
| **YOLOv8n** | 0.565 | 0.843 | 0.461 | 4.5 мс |
| **YOLOv8s** | 0.588 | 0.836 | 0.478 | 6.8 мс |
| **YOLOv8m** | **0.607** | **0.844** | **0.530** | 12.4 мс |
| **YOLO12n** | 0.592 | 0.806 | 0.506 | 6.6 мс |

Для итогового детектора была выбрана архитектура **YOLOv8m**, так как она продемонстрировала максимальную точность выявления критического класса `no_helmet` (0.530).

## 📈 Итоги тестирования
Тестирование лучшей модели проведено на контрольной выборке из 141 изображения:
- **Обнаружено касок:** 195
- **Обнаружено людей:** 249
- **Обнаружено нарушений (no_helmet):** 27
- **Доля кадров с нарушениями:** 12.77% (18 изображений)

## 🔍 Анализ характерных ошибок
1. **False Positives (Ложные срабатывания):** Модель классифицирует мотоциклетные/спортивные шлемы как строительные каски из-за визуального сходства геометрии.
2. **Occlusions (Перекрытия):** Пропуски детекций возникают при перекрытии силуэта рабочего строительными конструкциями (лесами, техникой) более чем на 40-50%.
